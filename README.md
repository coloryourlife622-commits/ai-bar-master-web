# AI Bar Master

【WEBアプリ概要】

オーセンティックなバーをイメージした、落ち着いたシックなデザインのAIチャットアプリ（AIバーマスターの悩み相談室）を作成してください。

【デザインテーマ・世界観】

- 全体的にダークモードを基調とした、高級感と落ち着きのある空間演出（ダークブラウン、深いネイビー、暖色系のゴールドや琥珀色のアクセント）。

- 背景には、照明の落ち着いたバーカウンターの雰囲気を感じさせる洗練されたデザイン。

- フォントや枠線は細めでエレガントな印象にしてください。

【画面構成・レイアウト】

1. ヘッダー：

   - アプリタイトル「AI Bar Master」と、「〜今夜の一杯と、あなたの相談〜」というサブタイトルをスタイリッシュに表示。

2. マスター表示エリア（中央上部）：

   - バーテンダーの立ち姿・またはカウンター越しをイメージした動画/画像が表示される円形または四角形のカード枠。

   - ステータスバッジ（例：「マスターが話を聞いています…」）を上部に薄く表示。

3. チャット会話エリア（中央）：

   - マスターからの吹き出し（左側）と、ユーザーの吹き出し（右側）で会話が展開するチャットUI。

   - マスターの吹き出しには「今夜のおすすめカクテル」や「マスターの一言」が際立つ専用のハイライトカードスタイルを含める。

4. 入力エリア（下部）：

   - 「マスターに悩みを打ち明ける…」というプレースホルダー付きのテキスト入力ボックス。

   - 落ち着いた琥珀色（ゴールド）に光る送信ボタン（紙飛行機アイコンまたは「話す」ボタン）。

   - クイック質問タグ（例：「仕事の悩み」「人間関係」「今夜のおすすめは？」など）を入力欄の上に小さなボタンとして配置。

【動作・フロントエンド仕様】

- ダミーデータで良いので、ユーザーがメッセージを送信したら、マスターが少し間を置いて優しく深みのある言葉で返答するアニメーション（タイピングエフェクト）を入れてください。

- レスポンシブ対応（スマートフォンでもパソコンでも綺麗に表示されるレイアウト）。
